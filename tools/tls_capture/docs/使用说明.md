# TLS消息捕获工具 - 使用说明

## 概述

本工具用于捕获TLS握手过程中的所有消息，以分析TLS协议的认证过程。

## 目录结构

```
tools/tls_capture/
├── tls_proxy.py          # Python代理工具（主要工具）
├── run_test.sh           # 自动化测试脚本
├── capture_client.c      # C语言客户端工具（可选）
├── Makefile              # C语言工具编译配置
├── README.md             # 英文说明
└── 使用说明.md          # 本文件
```

## 快速开始

### 最简单的方法

```bash
cd tools/tls_capture
./run_test.sh
```

这将自动完成所有步骤并捕获消息。

### 手动运行

1. **启动代理**：
```bash
cd tools/tls_capture
python3 tls_proxy.py 8443 localhost 4433
```

2. **在另一个终端启动服务器**：
```bash
# 创建证书（只需一次）
openssl req -x509 -newkey rsa:2048 -keyout server.key -out server.crt \
    -days 365 -nodes -subj "/CN=localhost"

# 启动服务器
openssl s_server -accept 4433 -cert server.crt -key server.key -www
```

3. **在第三个终端运行客户端**：
```bash
openssl s_client -connect localhost:8443
```

## 输出文件

运行后会在当前目录生成：
- `tls_all_messages.txt` - 所有消息的详细转储
- 时间戳目录（如果使用run_test.sh）- 包含所有相关文件

## 消息格式说明

每条消息包含：

1. **消息头部**：
   - 消息编号
   - 方向（Client->Server 或 Server->Client）
   - 时间戳
   - 消息长度

2. **记录层解析**：
   - ContentType（0x16=Handshake, 0x17=ApplicationData等）
   - Version（TLS版本）
   - Length（记录长度）

3. **握手层解析**（如果是握手消息）：
   - HandshakeType（0x01=ClientHello, 0x0B=Certificate等）
   - Length（握手消息长度）

4. **十六进制转储**：
   - 每行16字节
   - 左侧：十六进制
   - 右侧：ASCII字符

## 查看和分析消息

```bash
# 查看所有消息
cat tls_all_messages.txt

# 查看ClientHello
grep -A 50 "ClientHello" tls_all_messages.txt

# 查看Certificate消息
grep -A 100 "Certificate" tls_all_messages.txt

# 统计消息类型
grep "HandshakeType:" tls_all_messages.txt | sort | uniq -c
```

## 常见问题

1. **端口被占用**：
   - 修改脚本中的端口号
   - 或使用 `lsof -ti:8443 | xargs kill` 清理

2. **代理启动失败**：
   - 检查端口是否被占用
   - 检查Python3是否安装

3. **没有捕获到消息**：
   - 确保客户端连接到代理端口（8443），而不是服务器端口（4433）
   - 检查代理日志文件

## 技术说明

- **消息格式**：所有消息都是原始网络传输格式（第三方视角）
- **加密状态**：握手阶段明文，ApplicationData加密
- **字节序**：大端序（网络字节序）
- **固定字段**：记录层5字节，握手层4字节
