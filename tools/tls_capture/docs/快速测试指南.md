# 快速测试指南 - 无需编译

由于系统没有cmake，我创建了一个使用Python的解决方案，可以立即运行而不需要编译mbedtls。

## 方法1：使用Python代理（最简单）

### 步骤：

1. **启动Python代理**（终端1）：
```bash
cd /home/hosen/mbedtls
python3 capture_tls_python.py 8443 4433
```

2. **启动TLS服务器**（终端2）：
```bash
# 使用openssl创建测试服务器
openssl s_server -accept 4433 -cert server.crt -key server.key -www

# 如果没有证书，先创建一个：
openssl req -x509 -newkey rsa:2048 -keyout server.key -out server.crt -days 365 -nodes -subj "/CN=localhost"
```

3. **运行客户端**（终端3）：
```bash
# 使用openssl客户端连接到代理
openssl s_client -connect localhost:8443 -showcerts

# 或者使用自动化脚本
./run_test_now.sh
```

## 方法3：使用openssl完整测试

创建一个完整的测试脚本：

```bash
#!/bin/bash
# 创建自签名证书
openssl req -x509 -newkey rsa:2048 -keyout server.key -out server.crt -days 365 -nodes -subj "/CN=localhost"

# 启动Python代理（后台）
python3 capture_tls_python.py 8443 4433 &
PROXY_PID=$!
sleep 2

# 启动openssl服务器（后台）
openssl s_server -accept 4433 -cert server.crt -key server.key -www &
SERVER_PID=$!
sleep 2

# 运行客户端
openssl s_client -connect localhost:8443 -showcerts < /dev/null

# 清理
kill $PROXY_PID $SERVER_PID 2>/dev/null
```

## 输出文件

运行后会在当前目录生成：
- `tls_all_messages.txt` - 包含所有TLS消息的详细转储

每条消息包含：
- 消息编号和方向
- 时间戳
- 记录层解析
- 握手层解析
- 完整的十六进制转储

如果您想立即看到效果，可以运行：

