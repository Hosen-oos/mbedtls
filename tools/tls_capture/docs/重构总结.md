## 主要工具

### 1. tls_proxy.py（推荐）

Python实现的TLS消息捕获代理，功能完整，无需编译。

**使用方法**：
```bash
cd tools/tls_capture
python3 tls_proxy.py [proxy_port] [server_host] [server_port]
```

**特点**：
- 无需编译，直接运行
- 自动解析TLS记录层和握手层
- 生成详细的十六进制转储
- 支持多客户端连接

### 2. run_test.sh（推荐）

自动化测试脚本，一键完成所有操作。

**使用方法**：
```bash
cd tools/tls_capture
./run_test.sh
```

**功能**：
- 自动创建测试证书
- 启动OpenSSL服务器
- 运行客户端测试
- 捕获所有消息
- 自动清理
