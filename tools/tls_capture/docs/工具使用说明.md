# TLS消息捕获工具 - 快速使用

## 位置

所有工具已整理到：`tools/tls_capture/`

## 快速运行

从项目根目录：

```bash
./运行TLS捕获.sh
```

或：

```bash
cd tools/tls_capture
./run_test.sh
```

## 详细说明

查看 `tools/tls_capture/README.md` 或 `tools/tls_capture/使用说明.md`

## 工具列表

- `tls_proxy.py` - Python代理工具（主要工具）
- `run_test.sh` - 自动化测试脚本
- `capture_client.c` - C语言工具（可选）

所有工具都在 `tools/tls_capture/` 目录下。
