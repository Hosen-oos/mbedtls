# TLS消息捕获工具使用指南

我已经为您创建了多个工具来捕获TLS握手过程中的所有消息。以下是使用方法：

## 工具列表

1. **capture_tls_python.py** - Python代理工具（推荐，最简单）
2. **capture_tls_simple.c** - C语言捕获客户端
3. **run_capture_simple.sh** - 自动化脚本
4. **run_tls_capture.sh** - 完整自动化脚本（使用tcpdump）

## 方法1：使用Python代理（最简单，推荐）

### 优点：
- 不需要编译
- 不需要root权限
- 可以捕获所有原始网络数据
- 自动解析TLS记录层和握手层

### 步骤：

1. **启动Python代理**（在一个终端）：
```bash
cd /home/hosen/mbedtls
python3 capture_tls_python.py 8443 4433
```

2. **启动TLS服务器**（在另一个终端）：
```bash
# 如果已编译
cd programs/ssl
./ssl_server

# 或者使用其他TLS服务器
```

3. **运行客户端**（在第三个终端，连接到代理端口8443）：
```bash
# 如果使用mbedtls客户端，需要修改连接端口为8443
# 或者使用自动化脚本
./run_capture_simple.sh
```

4. **查看捕获的消息**：
```bash
cat tls_all_messages.txt
```

### 自动化运行：

直接运行脚本：
```bash
./run_capture_simple.sh
```

这个脚本会：
- 自动启动Python代理
- 启动服务器（如果已编译）
- 运行客户端
- 保存所有消息到时间戳目录

## 方法2：使用tcpdump（最准确）

### 优点：
- 捕获原始网络数据包
- 可以用Wireshark分析
- 最接近真实网络环境

### 步骤：

1. **启动tcpdump**（需要root权限）：
```bash
sudo tcpdump -i lo -w tls_capture.pcap port 4433
```

2. **启动服务器**：
```bash
cd programs/ssl
./ssl_server
```

3. **运行客户端**：
```bash
cd programs/ssl
./ssl_client1
```

4. **停止tcpdump**（Ctrl+C）

5. **查看捕获的数据**：
```bash
# 使用tshark（如果安装了）
tshark -r tls_capture.pcap -V > tls_messages.txt

# 或使用wireshark
wireshark tls_capture.pcap
```

## 方法3：使用C语言捕获工具

### 编译：
```bash
# 如果使用Makefile.capture
make -f Makefile.capture capture_client

# 或手动编译
gcc -o capture_client capture_tls_simple.c \
    -I./include -I./library \
    -L./library -lmbedtls -lmbedx509 -lmbedcrypto \
    -lpthread -ldl
```

### 运行：
```bash
# 1. 启动服务器
programs/ssl/ssl_server &

# 2. 运行捕获客户端
./capture_client tls_all_messages.txt
```

## 输出文件说明

捕获工具会生成以下文件：

### tls_all_messages.txt
包含所有TLS消息的详细信息：
- 每条消息的编号和方向（Client->Server 或 Server->Client）
- 时间戳
- 记录层解析（ContentType, Version, Length）
- 握手层解析（HandshakeType, Length）
- 完整的十六进制转储
- ASCII字符显示

### 消息格式示例：
```
==================================================
Message #1: Client->Server
Time: 2024-01-31 14:30:25
Length: 154 bytes
Record Layer:
  ContentType: 0x16 (Handshake)
  Version: 0x0303
  Length: 149 bytes
Handshake Layer:
  HandshakeType: 0x01 (ClientHello)
  Length: 145 bytes
--------------------------------------------------
Hex Dump:
0000: 16 03 03 00 95 01 00 00 91 03 03 ...
...
==================================================
```

## 注意事项

1. **端口冲突**：确保端口4433和8443没有被占用
2. **防火墙**：如果使用远程服务器，检查防火墙设置
3. **权限**：tcpdump需要root权限，Python代理不需要
4. **编译**：如果使用C语言工具，需要先编译mbedtls库

## 查看捕获的消息

所有消息都保存在文本文件中，可以直接查看：

```bash
# 查看所有消息
cat tls_all_messages.txt

# 查看特定消息类型
grep "ClientHello" tls_all_messages.txt -A 20

# 查看服务器证书
grep "Certificate" tls_all_messages.txt -A 50
```

## 故障排除

1. **"Connection refused"**：确保服务器已启动
2. **"Permission denied"**：tcpdump需要sudo
3. **"Module not found"**：确保Python3已安装
4. **编译错误**：检查mbedtls库是否已正确编译
